# SİNETECHNİC GİDER

Gider fişlerini telefondan fotoğrafla toplar, fiş tarihine göre aylara ayırır ve her ay muhasebeciye Excel + birleşik PDF olarak gönderir.

- 📱 Telefon sayfası: https://wolkansezer.github.io/sinetechnic-gider/ (GitHub Pages, `docs/`)
- ☁ Fişler özel bir GitHub deposunun `gelen/` klasörüne yüklenir; PC programı her dakika çeker ve depodan siler
- 📅 Teslim protokolü: ay fişleri sonraki ayın 14'üne kadar; 10'unda otomatik e-posta; geç gelenler "EK" paket
- 🧾 Windows OCR ile tarih/tutar/KDV okuma

Bu depoda **fiş veya anahtar bulunmaz** — anahtar yalnızca PC ayarlarında (DPAPI şifreli) ve telefonun kendi hafızasında durur.
